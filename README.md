# Ветви — атлас данных

Мини-проект для интерактивной визуализации иерархии. Чистые HTML, CSS и JavaScript, без зависимостей и внешних запросов.

## Запуск

Откройте index.html двойным щелчком в актуальном Chrome, Edge или Firefox. Установка и сервер не требуются. Все четыре файла интерфейса и примера можно свободно переносить вместе с папкой.

## Возможности

- Горизонтальное дерево с цветом каждой основной ветви.
- Выбор узла: описание, значение, путь и число потомков.
- Сворачивание ветвей и раскрытие всего дерева.
- Поиск по имени без учёта регистра, с раскрытием предков найденных узлов.
- Масштаб 25–200%, подбор масштаба и прокрутка карты.
- Загрузка файла или вставка JSON, проверка данных, скачивание текущего дерева.
- Управление узлами клавишами Tab, Enter и пробел; клавиша / переводит фокус в поиск.
- Адаптивная компоновка для узких экранов.

## Формат данных

Один корневой объект:

```json
{
  "name": "Компания",
  "description": "Необязательное описание",
  "children": [
    { "name": "Разработка", "value": 12 },
    { "name": "Дизайн", "children": [{ "name": "Исследования" }] }
  ]
}
```

name обязателен: непустая строка до 120 символов. description — строка до 2000 символов. value — строка до 500 символов, конечное число, логическое значение или null. children — массив таких же объектов. Неизвестные поля не сохраняются. Имена могут повторяться: идентификаторы создаются внутри приложения.

Ограничения: 500 узлов, 20 уровней, входной файл до 1 МБ. Вставленный текст ограничен 1 миллионом символов. Пример расположен в example.json.

Данные хранятся в памяти вкладки. Чтобы сохранить изменения перед обновлением страницы, нажмите «Скачать JSON». Они не отправляются на сервер. Кнопка «Пример» возвращает исходную демонстрационную структуру.

При поиске показывается вся доступная карта, совпадения выделяются, их предки раскрываются. Сворачивание ветви очищает поиск. Кнопка «Свернуть» оставляет первый уровень направлений под корнем.

## Файлы

- index.html — структура интерфейса.
- styles.css — оформление и адаптивная компоновка.
- app.js — проверка JSON, раскладка SVG, поиск и обработчики.
- example.json — демонстрационные данные.

## Проверка

Синтаксис JavaScript и 14 проверок логики выполнены в Node VM с моделью DOM: подсчёт узлов, экспорт и повторная загрузка, сворачивание, поиск, раскрытие предков, ограничения данных, сохранение дерева при ошибке и нулевые значения. Проверка настоящим браузером и визуальная проверка не выполнялись.
